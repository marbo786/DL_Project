# Single-image evaluation protocol v1

The task is detection and localization of localized visual edits from one receipt image. The reference-assisted comparator is a separate task with its own [frozen policy and acquisition protocol](history/REAL_WORLD_VERIFICATION_ANALYSIS.md).

| Input partition | Role in this protocol |
| --- | --- |
| AIForge v2 historical training | Fit model weights. Set aside source groups deterministically for calibration. Those sources have prior project exposure. |
| AIForge v2 historical validation | Development evaluation. All previous exposure carries forward. |
| AIForge v2 historical test and WildReceipt | Previously scored historical evaluation. WildReceipt changes corpus while holding the generator fixed. |
| Previously excluded AIForge v2 XFUND forms | Held-back cohort from the same package. These forms change document category and corpus together while holding the generator fixed. |
| New audited sources | Future confirmatory evaluation. The [fresh shift protocol and evidence status](FRESH_SHIFT_EVALUATION.md) specify source intake, cross-release lineage review, and the common-cohort lock. |

Reserve approximately 20% of historical training using the first eight hex digits of SHA-256 of `forgerylens-calibration-v1:` plus the connected source ID, modulo five. Exact decoded-pixel matches and reviewed same-source links join source identities transitively. Provisionally contain every unresolved perceptual candidate in the same component and quarantine components crossing historical partitions. A numerical candidate screen can miss recaptures and crops. Verified lineage and human review are needed for confirmatory data. V2 metadata's v1 assignment is a pairing lead only. A valid generator comparison requires the same underlying sources and edit specifications, both actual image versions, and separation from all fitting groups. Physical acquisition is a separate shift.

The main comparison uses identical MobileNetV3-Small initialization and matching patch data for frozen, last-three-block and full fine-tuning. Compare full RGB with residual-enhanced full and whole-image full. Training uses native 112 px tiles, 112 px stride, at least 0.5% mask overlap for positive tiles, same-location genuine negatives and negatives from the highest-edge-density off-mask tile. A whole-image control resizes the document to 112 × 112. Inference grids use image geometry alone. Average the highest three tile logits for detection. The highest-scoring tile is the localization prediction. Its overlap with annotated pixels and authentic false alarm rates are reported separately. Use fixed schedules and the final epoch. A pilot smoke test verifies finite losses and parameter updates. Main runs use seeds 17, 42, and 71 and nested, source-hash-ordered training fractions. Rank candidate methods by mean development AUROC across seeds, using AP to break ties. Each seed has independent fitted weights and calibration. Results on the development set used in this ranking are descriptive.

Fit Platt calibration on the designated calibration pool. Use its authentic scores to select strict-greater-than cutoffs targeting 1%, 5%, and 10% FPR. Report achieved FPR and recall together. AUROC and AP are primary for detection. Highest-tile IoU and hit rate on edits are primary for localization, with fixed-policy authentic flags reported alongside. Report macro F1, positive precision and recall, confusion matrices, Brier score, equal-width ECE, reliability bins and fixed-confidence risk and coverage with class strata. Compare calibration and selection with a constant predictor fit to the calibration prevalence. Report source-group resampling intervals and matched paired AUROC deltas. Report seed variability independently.

Stress testing uses the same 24 hash-selected development source groups at two levels per disturbance, with identical settings across classes. Combined disturbances form a separate condition. A stress subset drawn from development remains development evidence. A retrospective probe may score the two historical holdouts after freezing the development-selected recipe with seed 42 and its calibration. Physical capture and real-world authenticity require independent evidence beyond these experiments.

The receipt importer excluded all 418 XFUND form sources. Before inspecting form images, masks or scores, lock the highest mean-development-AUROC recipe, seed 42 checkpoint, calibration and thresholds. Use all forms that pass strict metadata pairing, aligned mask verification and source overlap screening against every historical receipt partition. Compare exact decoded hashes for originals and edits and screen authentic thumbnails with the same perceptual rule as the receipt audit. Contain suspected aliases conservatively and quarantine any form component linked to a receipt candidate. Report forms separately with the frozen receipt operating points. A result on this held-back cohort has scope limited to a new corpus and category inside the same AIForge release.
